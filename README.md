# Hurtigkommandoer

- `python generer.py --test <nokkel>` - rendrer ett verktoy til tmp/
- `python generer.py --alle-test`  - rendrer alle til tmp/
- `python generer.py --publiser`   - publiserer neste fra ko.txt (krysser av, oppdaterer logg + hub)
- `python test_logikk.py`          - kjorer alle verktuys JS i Node og sjekker tall
- `python build.py`                - bygger hub/index.html pa nytt

Nye verktoy legges til i LIB-dicten i generer.py og i ko.txt.
